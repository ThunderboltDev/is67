# six sevennnnnn

Checks whether a number is 67.

# Install

```bash
npm i six-sevennnnnnn
```

# Usage

```js
const is67 = require('six-sevennnnnnn');

is67(67); // returns true
```

# Why?

Becasue using `num === 67` lacks clarity, your codebase deserves better.

# FAQ

What about other numbers? For other numbers just use `===` directly. They don't deserve their own package.
